# CK Core CDE

CK Core CDE maintains the classic Common Desktop Environment and its native
applications on current Unix systems. The desktop includes the CDE window and
session managers, Front Panel, File Manager, Terminal, Style Manager, Help,
calendar, mail, application builder, and supporting desktop services.

The project builds against CK Core Motif ABI 9. CDE subclasses Motif widgets
and uses private widget records, so the toolkit and desktop form one native ABI
cohort and must be rebuilt together.

See [the running desktop](desktop.md) for screenshots from the automated ARM64
desktop smoke test. See [building CDE](build.md) for the source build and
toolkit requirements.
